========================================
 koutu 徽章处理工具 —— 使用说明（v1.1）
 把徽章照片处理成可以直接付印的排版页
========================================

一、这个程序能做什么（三个页签）
--------------------------------
1. 抠图：自动识别照片中间的圆形徽章，裁成透明背景 PNG。
   输入「原图」文件夹 → 输出「底图」文件夹。
2. 排版：按模板图（排版demo.png）上的圆形槽位，把底图排成多页 A4 尺寸 PNG。
   输入「底图」文件夹 + 排版demo.png → 输出「已排版」文件夹。
3. 去水印：入口占位——本版不提供去水印处理（算法后续版本提供）。
   页签内只有说明文字，点击不会执行任何操作。

二、怎么用（图形界面）
--------------------------------
1. 把整个文件夹拷到任意 Windows 电脑（路径可以有中文和空格）；
2. 双击 koutu.exe 启动；首次运行会自动创建「原图」「底图」文件夹；
3. 抠图：把照片（jpg / jpeg / png / bmp / gif / tif / tiff）放进「原图」，
   切到「抠图」页签，点「开始抠图」：
   - 扫描阈值：默认 45，可调 10–200（浅色徽章扫不到时调小再试）；
   - 羽化宽度：默认 4 像素，可调 0–20（边缘过渡的柔和程度）；
   - 取消：在「当前一张处理完」之后停止，不会打断正在处理的那张。
4. 排版：把底图放进「底图」，确认 排版demo.png 与 koutu.exe 在同一文件夹，
   切到「排版」页签，点「开始排版」；
   - 「添加定位点」默认勾选，右侧「样式」可选「黑三角」（默认）或「红点」：
     黑三角 = 每个槽位内侧统一画一个小三角；红点 = 圆盘正上方统一画一个纯红圆点
     （与新版模板自带的红点标记同位，付印对齐用）；两者都不依赖模板内容；
   - 取消勾选 = 不画（与旧版输出一致）；勾选与样式都会记住。
   - 模板既可以是「圆内有图案」的版式，也可以是「圆内空白、只有一圈细圆环」的
     空心模板（自动适配，无需配置）。
   - 换批次：先清空或替换「底图」里的旧图片再运行（本批输入 = 「底图」里的全部图片）。
5. 完成后点「打开输出目录」直接查看结果。

三、命令行（批处理，可选）
--------------------------------
在程序所在文件夹打开 PowerShell 或命令提示符：

  koutu.exe cutout                      # 抠图：原图 → 底图
  koutu.exe cutout --src 目录 --dst 目录  # 自定义输入输出目录
  koutu.exe layout                      # 排版：底图 + 排版demo.png → 已排版
  koutu.exe layout --no-anchors         # 排版但不画定位点（与界面勾选框同义）
  koutu.exe layout --anchor-style dot   # 定位点用「红点」（默认 triangle=黑三角）
  koutu.exe watermark                   # 去水印：占位命令（本版不处理；退出码 2）

说明：命令行方式给 --dst 指定的目录不存在时，会自动创建多级目录（图形界面只创建
最后一级、父目录必须已存在）；自定义输出目录不会被自动清理（见「五、自定义目录」）。

退出码：0 = 全部成功；1 = 有文件失败；2 = 出错或占位命令。
（打包版从命令行启动时，输出会打印在当前控制台：cmd 下可直接等待结果；PowerShell 里
请用 Start-Process -Wait（或给命令加管道），否则命令会立刻返回、取不到真实退出码。
完成判定以「运行日志.txt / 排版日志.txt」与退出码为准。）

四、日志与设置（都在程序所在文件夹）
--------------------------------
- 运行日志.txt —— 抠图：逐张结果（尺寸 / 圆心 / 半径）与成功失败汇总；
- 排版日志.txt —— 排版：槽位识别（含回退标注）、圆盘实测（圆心 / 圆径）、底图清单、每页槽位分配表、定位点状态与样式；
- koutu.ini    —— 界面记忆（窗口位置、上次页签、参数）；
                  程序文件夹不可写时会自动存到 %APPDATA%\koutu\koutu.ini。
日志里的统计行是核对处理是否正确的主要依据；遇到问题请连同日志反馈。

五、自定义输入/输出目录（可选）
--------------------------------
1. 「抠图」「排版」页签的输入、输出目录都可以改：
   - 直接在路径框里输入：相对路径按程序所在文件夹解析，绝对路径原样使用；
   - 点「浏览…」选择文件夹（可在对话框里新建文件夹）；
   - 点「恢复默认」随时改回默认目录（抠图：原图 → 底图；排版：底图 → 已排版）。
2. 程序会记住每个目录最近一次的选择（存在 koutu.ini），下次打开自动恢复；
   如果记住的目录不可用了，会自动改回默认并在界面提示。
3. 开始任务前程序会校验目录，遇到下列情况会中文提示、不启动任务：
   目录不存在（或无法创建）；没有写入权限；盘符不存在；输出目录与输入目录相同；
   路径过长（超过 259 个字符）。
4. 安全规则（重要）：只有默认的「已排版」目录会在写入前清空旧 *.png（与旧版一致）；
   自定义输出目录不会被程序清理——只写不删，同名产物直接覆盖，日志里会提示
   「同名覆盖 N 个 / 检测到本工具旧页 N 张（不清理）」。想要干净的结果，请先自行
   清空自定义目录。
5. 自定义输出目录不存在时，程序只创建最后一级（父文件夹必须已存在），不会一次
   生成一串新目录；命令行 --dst 的创建规则见「三」节的说明。
6. 任务运行期间，目录框、浏览与恢复默认按钮会暂时不可用，任务结束后恢复。
7. 「打开输出目录」打开的是当前选择（或输入）的目录；目录不存在时按第 5 条规则
   创建，创建不了会中文提示。

六、常见问题
--------------------------------
Q：双击后提示「Windows 已保护你的电脑」（SmartScreen）？
A：程序未做代码签名。点「更多信息 → 仍要运行」即可。

Q：去水印页签为什么不能点？
A：本版只保留入口占位，去水印算法将在后续版本提供。

Q：排版提示「找不到模板文件 排版demo.png」？
A：把 排版demo.png 放回与 koutu.exe 相同的文件夹（换版式 = 换这张图）。

Q：处理到一半想停？
A：点「取消」，会在当前一张处理完成后停止；已完成的结果保留。

Q：输出文件在哪里？
A：抠图 →「底图」文件夹；排版 →「已排版」文件夹，都在程序所在文件夹里。

Q：换了新的一批徽章，排版结果里混进了旧图？
A：排版会把「底图」文件夹里的所有图片当作本批输入；换批次前请先清空或替换「底图」。

Q：自定义输出目录里为什么还留着上次的旧页？
A：为了不误删你自己的文件，程序对自定义输出目录只写不删；请自行清理，或改用默认
   「已排版」目录（默认目录每次都先清空旧页）。

Q：排版页上每个徽章顶部的小三角是什么？
A：「定位点」，本工具在每个槽位统一绘制的付印对齐标记，不依赖模板内容；
   两种样式：「黑三角」（默认，画在槽位内侧）与「红点」（圆盘正上方，与新版模板
   自带的红点同位）；在「排版」页签的「样式」下拉切换，或 CLI 加 --anchor-style dot；
   不需要时取消「添加定位点」（或 CLI 加 --no-anchors）。

六、文件夹是接口（不要改名、不要删除）
--------------------------------
原图 / 原图_去水印 / doubao / 底图 / 无水印 / 无水印_AI重绘 / 无水印_精修 /
无水印_细纹轻 / 无水印_细纹重 / 无水印底图 / 去水印_预览 / 已排版 / 水印诊断
这些文件夹名是给操作者的固定接口；本版程序的自动流程只读写
「原图 → 底图 → 已排版」，对「无水印」系文件夹没有任何自动写入。
