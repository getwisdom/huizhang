## 3. 架构级关键结论（工程师必读，避免重复推导）

### 3.1 抠图（W1 已固化）

- **必须逐位复刻 .NET `System.Random(2024)`**（`koutu/core/dotnet_random.py`，内置 PowerShell 实测向量测试）：否则 RANSAC 采样序列偏移 → 圆周亚像素差异 → 直接击穿 alpha 容差。
- 扫描 / RANSAC / 精修 / 羽化参数语义：以 `koutu/core/cutout.py` 模块 docstring 为准（与 `legacy/抠图工具.cs` 逐项对照）。

### 3.2 排版合成（W2 最大隐性坑，务必继承）

- GDI+ `HighQualityBicubic` 的真实插值核 ≠ 任何教科书核：黑盒实测等效为
  **`mitchell(B=0.25, C=0.875) ⊛ box(0.75)`**（像素边帧相位、逐相 Σ≡1、6 抽头；查找表实现见
  `koutu/core/layout.py::_gdi_kernel_table`）。探针与拟合脚本：`spike/layout_calibration/`。
- 槽位目标框（`2r+2` 见方）**互相重叠**且必须**按槽序 `SourceOver` 叠加**——透明像素保留画布已有内容，
  **禁止「白底合成直写」**（修复前后整页差异 0.628% → 0.0131%）。实现：`layout.py` 的采样 alpha + 重混合。

### 3.3 水印（W3 测绘约 80%，去除功能未实现）

- 水印沿整幅照片铺排；**底图四角（圆外背景）为最佳观测区**：残差 std≈**2.0**（徽章内部纹理 std≈44，信号被淹没）。
- 点阵几何（1.png 实测）：自相关峰 **(±26, 0) / (0, ∓26)**、半阶 **(±13, 0)** → **≈26px 准正交**（约 1° 倾斜）；
  亚像素初值 `b1=(26.104, 0.067)`、`b2=(0.972, 25.995)`。与旧注「约 27px 方格斜向」同量级（精确值≈26）。
- 26×26 相位折叠可重建**跨四角一致的重复字形结构**（9216 样本、≈14 样本/格；结构显著性 1.2–1.9σ；
  27 正交折叠因 1px 漂移被抹开）。`research6.py` 冒烟复核通过（精修基 `b1=(26.104,0.267)`、
  `b2=(0.671,26.588)`，最优相位 (0,0)，折叠方差 741；精修以折叠方差为目标，供工程师复核）。
- **建议技术路线（供 3.2 选型评审）**：相位折叠模板扣除（数据驱动、确定性、无模型假设）；
  备选对照：残差域高斯点 NCC（旧思路）；不建议：全局模糊类（旧 detex，属近似手段）。
