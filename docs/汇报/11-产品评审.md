## 三、B 题最终建议（自定义输出目录名与安全规则）——二选一结论

### 3.1 结论：选 **②「统一改为仅清理本工具产物命名模式」**

即：**无论默认还是自定义输出目录，写入前只清理与本工具页命名一致的旧页（匹配 `第N页.png`），其余文件一律不动；清理清单记入排版日志。** 不采用 ①「仅默认目录清空 `*.png`、自定义目录不清理」。

### 3.2 理由

1. **① 只治过敏源、留着病根**：自定义目录不清理 → 上次跑 3 页、本次只出 1 页时，`第2页.png`、`第3页.png` **残留**，下游使用结果集的人看到的是错误集合；② 对"清旧页"的目的（避免残留）在两种目录下都成立。
2. **② 把误删风险从根上消掉**：实验 E4 证明，现在只要输出目录里存在任意 `*.png`（哪怕是与工具无关的 `我的照片.png`），都会被删除；② 之后，删除范围收敛到工具自己的命名空间，默认目录同样受益。
3. **② 是单一规则**：默认与自定义一套语义，文档、测试、验收各只有一份口径；① 是两套语义（默认删/自定义不删），还需另补"残留旧页怎么办"的解释，维护与培训成本更高。
4. **对"默认不退化"影响最小**：默认目录的历史语义是"清掉上一次的旧页"，而旧页都叫 `第N页.png`；② 下该行为**完全不变**。唯一变化是"非工具命名的 PNG 不再被删"——那不是任何验收场景依赖的行为。

### 3.3 配套规则（创建 / 覆盖 / 清理）

- **创建**：默认目录照旧自动创建；自定义输出目录只创建最后一级（父目录必须已存在），不自动创建未知多级路径。浏览对话框原生支持「新建文件夹」完成"在所选父目录下新建自定义名称"。
- **覆盖**：同名产物直接覆盖（保持现状）；但 GUI 在任务启动前统计并在**日志与状态行**给出不打断的提示（如「输出目录已有 3 个同名产物，将被覆盖；将清理旧页 2 张」）。
- **清理**：仅删 `第N页.png`（大小写不敏感、仅顶层、不递归）；被删清单写日志；个别文件删不掉（被占用）时记日志而非静默忽略。
- **执行时机**：维持「校验通过后、生成前」先清后写（若中途失败/取消，旧页已清——② 后其影响面已收敛为工具自己的旧页，可接受）。

### 3.4 页名前缀等"命名可定制"评估：**本批不做**

现规格已锚定 `第N页.png`（无零填充、无日期前缀，`badge-layout\spec.md:55`），golden 对照、槽位分配表、验收清单、使用说明均按此对齐；引入前缀会联动"清理模式、验收判据、单测、文档"四处，收益低。记录为后续版本可选项（如做，清理模式必须随当前命名规则走，避免又出现"删不干净/删错"）。
