## ① 实现要点与关键校准

1. **槽位识别逐位复刻**：step=4 / 阈值 60 / 最小 300 / 合并 IoU 0.3 / 外扩 6 / 十字弦 / 半径下限 300；对 `排版demo.png` 实测 11 槽、r=414.0，中心与基线逐字一致（首槽 `(474.5,448.5)`）。
2. **合成必须复现 GDI+ `HighQualityBicubic` 的真实行为**——用 .NET（PowerShell + System.Drawing）做黑盒探针实测：
   - 平坦场探针：任意相位下常数场保持精确（Σw≡1），据此排除了「插值核」假设；
   - **灰底脉冲探针**（揭示负瓣）：实测核 = `mitchell(B=0.25, C=0.875) ⊛ box(0.75)`，逐相 Σ=1.0000、残差 ≤2 灰阶；采样相位为「像素边帧」（edge 约定），6 抽头实现；
   - 结论固化在 `layout.py` 的 `GDI_B/GDI_C/GDI_BOX` 与 `_gdi_kernel_table()`（查找表 + 插值）。脚本与原始数据留档 `spike/layout_calibration/`。
3. **叠加语义 = GDI+ `SourceOver`**：旧工具把 830×830 目标框**按序叠加**（目标框互相重叠，如槽1×槽3 重叠 57×414），后画者的内容（含其目标框角部的徽章边缘弧）会覆盖先画者；透明像素**保留画布已有内容**。我们按「白底补丁 + 采样 alpha 重混合」实现后，差异从 54,656 → 1,141。
4. 底图读取：`StrCmpLogicalW` 自然序、alpha>16 包围盒、全透明跳过并记日志（`跳过 <name>：没有有效内容`）。
