## ⑤未验证与风险

- **GUI 完整点击流程在打包版未做人工点检**：打包版做了启动核验（窗口标题 / 首启建目录 / 正常退出），完整页签操作由 W4 源码版实跑留档（同一 GUI 代码路径）；建议使用者闲时双击复看一遍。
- **SmartScreen / 杀软**：本机 Defender 实时防护处于关闭状态（见 `docs/环境验证.md` §6.2），实测无任何拦截弹窗；未签名 exe 在启用防护的机器上可能提示——已在 `使用说明.txt` 常见问题里写明处理方式；代码签名仍属范围外。
- **打包版无控制台**（`--windowed` 设计口径）：CLI 证据以「日志文件 + 退出码」为准；控制台孪生 exe（`koutu-cli.exe`）仍是 design 开放项（见⑥-3）。
- **未在第二台真机 / 虚拟机验证**：以本机干净 `PATH` 会话模拟（验收清单允许的替代），另注意交付包为 onedir，必须 exe 与 `_internal\` 一起拷贝。
- UPX 未启用压缩（本机无 UPX；不影响功能与验收）。
