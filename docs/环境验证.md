## 7. 异常、坑与绕法（全部实测踩过）

1. **winget download/install 在本机不可用（慢 + 卡死）**：15 分钟只完成 14MB 且不退出；另清掉一个 23:06 起的既有卡死进程。绕法：`curl` 直连镜像下载 + 手动校验（§2.1）。注意 `%TEMP%\WinGet` 里还剩 Git.Git 2.55.0.5 与 Python 3.12.10 两份半成品，未动。
2. **国际源慢**：python.org 直链 ~16 KB/s。绕法：华为云镜像（装机 11.6 MB/s）、pip 用 `-i https://mirrors.huaweicloud.com/repository/pypi/simple`（HTTPS，无需 --trusted-host）。
3. **PowerShell 5.1 编码三连坑**（最容易害人）：
   - `.ps1` 文件没有 BOM 时，PS 5.1 按 GBK 读，**含中文的脚本直接语法报错**（本次 `run_test.ps1` 实测踩中）。修复/预防命令：
     ```powershell
     $p='<脚本路径>'; [IO.File]::WriteAllText($p, [IO.File]::ReadAllText($p,[Text.Encoding]::UTF8), (New-Object Text.UTF8Encoding $true))
     ```
     （本仓库约定的 UTF-8：`.py/.md/.txt` 无 BOM 没问题；**`.ps1` 必须带 BOM**。）
   - PS 5.1 `Get-Content` 读 UTF-8 文本默认按 GBK → 乱码，必须加 `-Encoding UTF8`（本次读 `.gitignore` 实测）。
   - 用工具（编辑器/AI）写出去的文件默认无 BOM，写 `.ps1` 后要过一遍上面的补 BOM 命令。
4. **`python -c "多行代码"` 经 PowerShell 传参会吞引号** → 直接 SyntaxError。绕法：把多行代码写成 `.py` 文件再执行（本次探针就是这么做的）。
5. **pip 输出经管道时 PS 会打 `NativeCommandError` 噪音**（例如升级提示、进度条走 stderr），不是错误——以 `$LASTEXITCODE`（本次恒为 0）为准；日志用 `2>&1 | Tee-Object -FilePath …` 保完整。
6. **截图首跑瞬态失败**：见 §4 与 §8。
