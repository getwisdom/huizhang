## 阶段 1 —— 抠图（批次）

对照物：`golden/baseline_products/底图/`（7 张）、`golden/logs/run_final/运行日志.txt`（统计行）

运行新实现（在含 `原图\` 的独立「运行目录」里执行，输出写进 `底图\`；日志写入程序根——源码版=仓库根）：

```powershell
# 源码版（开发机）
.\.venv\Scripts\python.exe -m koutu cutout --src <运行目录>\原图 --dst <运行目录>\底图
# 打包版
koutu.exe cutout --src <运行目录>\原图 --dst <运行目录>\底图
```

判据（逐项打勾）：

- [x] 输出文件名集合与基线一致：`1.png…6.png、测试_1.png`（不多不少）
- [x] 日志输出含 7 条 `[完成]` 且末行 `全部完成：成功 7 张，失败 0 张`（格式可换，语义须等价）
- [x] 每张输出的宽高与日志中的 `417x417` 等值一致
- [x] **圆心 ±2px**（逐张对照基线统计行，如 1.jpg 为 `圆心(414,365)`）
- [x] **半径 ±2px**（如 1.jpg 为 `半径200`）
- [x] **不透明像素数（alpha>0）±0.5%**（基线值见 pixel-diff 输出 `opaqueA`）
- [x] 像素级草案：alpha 差>8 占比 ≤0.5%、最大 alpha 差 ≤64、RGB 差>8 占比 ≤0.5%
  - 实测（2026-10-06 W1）：7/7 全部 `alpha>8=0、maxAlphaDiff=0、rgb>8=0`；opaque 逐张相等；圆心/半径逐字一致（证据：`docs/汇报/06-W1-抠图内核.md`、`golden/scripts/pixel-diff.ps1` 输出）

量化命令（示例）：

