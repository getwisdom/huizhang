# 水印研究（W3.1 测绘 + W3.2 选型）

- 状态：W3.1 定稿；W3.2 选型**待使用者目检确认**（确认后进入 W3.3 原型与样张）。
- 依据：`docs/汇报/08-架构交接.md` §3.3（继承结论）、`spike/watermark_research/`（research4/5/6 有效工具）、本波新增 `research7.py` / `research8_cross.py`。
- 纪律：旧去水印产物（`无水印*` / `去水印_预览` / `水印诊断` 等）一律不作数；本文件只记录可复核的实测。

## 1. 继承结论（来自 08-架构交接 §3.3，不重新推导）

1. 水印沿整幅照片铺排；**底图四角（圆外背景）为最佳观测区**：残差 std≈2.0（徽章内部纹理 std≈44，信号被淹没）。
2. 点阵 ≈ **26px 准正交**（自相关峰 (±26,0)/(0,∓26)、半阶 (±13,0)；亚像素初值 b1=(26.104,0.067)、b2=(0.972,25.995)）。
3. **26×26 相位折叠可重建跨四角一致的重复字形结构**（9216 样本、≈14 样本/格；结构显著性 1.2–1.9σ）。

## 3. 统计口径（三个数的定义）

- **间距**：四角拼接自相关（±26 邻域抛物线亚像素插值）取最强两个非平行峰为基 b1、b2；报告 |b1|、|b2|（px）与夹角。
- **幅度**：观测区（alpha==0，圆外背景）残差（亮度 − 中值21）的 std / p1 / p99（灰度级）；另报 26×26 折叠字形的峰谷（p98−p2）。
- **覆盖率**（三个子口径）：
  - ①**观测区占比**＝alpha==0 像素/全图面积（可测区大小）；
  - ②**铺排覆盖率**＝点阵铺排范围（见 §5 论据，结论为全幅）；
  - ③**格内笔画覆盖率**＝26×26 折叠字形中 |值|≥1.0 灰度级的格点占比（扣除将触及的格点比例量级）。

## 5. 补充发现（本波实测）

1. **4.png 与 5.png 为同一内容重复**（逐像素最大差 = 0，`research8_cross.txt`）。统计独立样本为 6 张；其余两两均不同源。
2. **测试_1.png 角区不可测**：其观测区残差 std=26.6（角区被照片内容占据，非平坦背景），自相关基不落在 26px 族、折叠结构 0.99σ≈噪底。→ 该图**无法在场内自估点阵**；去除时需按「不可测」分支处理（沿用共享基/幅度或跳过显著扣除，W3.3 定）。
3. **半阶（13×13）折叠显著度高于 26×26**（2.44–2.81σ vs 1.78–2.01σ），提示 26px 格内含两个 13px 子单元，与旧注「约 13px 的小字符、按约 27px 方格斜向铺满」吻合。→ W3.3 原型将用 13px 与 26px 两口径做对照取优。
4. **跨图一致性高**：α=0 观测区 26×26 折叠字形两两循环位移最大相关 **+0.91～+0.99**（1–6 张；测试_1 与其余仅 +0.37）。支持「同一重复结构铺排」的判断（铺排覆盖率论据）。
5. 观测区结构与 RGB 三通道等量（三通道残差 std/相关逐位相同）→ 幅度按灰度等量扣除处理。
6. 角区观测质量在单图内也可能不均（如 1.png：对角两角信号清楚、另两角近平坦）；相位估计需覆盖全部 alpha==0 像素而非单角。

## 6. 对去除方法的含义

- 可观测幅度量级：观测区残差 std ≈1.8–1.9、字形峰谷 ≈1.7–2.0 灰度级、相干结构 1.8–2.8σ。**水印可见目标主要是圆外背景上的弱亮点阵**（徽章面不可直接观测，按全幅同一铺排处理）。
- 扣除幅度上界 ≈ 字形峰谷（±3 灰度级以内），对徽章面属「在纹理噪声下的不可见微调」——这是「非水印区保真」指标的物理基础。
- 观测区样本量：≈63 样本/格（α=0 全部）；模板估计噪底 ≈0.22–0.23 灰度级/格。

## 7. W3.2 方案选型（2–3 条确定性候选）

### 候选 A（推荐）：相位折叠模板扣除

- **做法**：① 由 α=0 观测区自相关亚像素峰估基 + 折叠方差搜索定相位（确定性网格搜索）；② 以 26×26（或 13×13 半阶）把观测区残差折叠成字形模板；③ 对全图逐像素减去所在格点的模板值（幅度 k 由观测区最小二乘拟合，RGB 等量、alpha 不动、0–255 夹取）。
- **优点**：确定性（无随机、无逐图阈值魔法数）；数据驱动（不假设点形/字符模型）；逐像素可复核；改动幅度有界（≤字形峰谷）。
- **局限**：模板受观测区样本量限制（噪底≈0.22/格）；对观测量极弱的结构（徽章面）只有「微调级」作用。
- **预期指标（初定，W3.3 样张后校核定稿）**：
  - 幅度降幅：观测区相干幅度（匹配滤波口径，留一法）显著下降；残差 std 降幅 ≥2%（全观测区口径）；
  - 非水印区保真：徽章面 |Δ| p99 ≤2、max ≤6 灰度级；
  - 伪影：扣除后残余重做折叠检出不显著（σ 回落至噪底附近），无新增条纹。

### 候选 B（对照）：残差域高斯点 NCC

- **做法**（旧思路）：残差域用高斯点模板（σ≈4.4、尺寸≈21 量级）逐格点 NCC，超阈值处按实测幅度扣除、逐点幅度夹取。
- **取舍**：局部适应好；但阈值/幅度需逐图调（非纯数据驱动），纹理区亮点与「点」难以区分、易误伤；预期非水印区改动不可控（p99 可能 >2 灰度级）。保留为 A 的对照实现。

### 候选 C（不建议）：全局模糊/中值类（旧 detex 路线）

- **取舍**：能显著降纹但全局变软（旧实测整图 mean|Δ|≈7.8、max≈150、54% 像素被改），属近似手段、不建模水印形态、损伤面大，违背「非水印区保真」。**弃**。

### 选型结论（待使用者确认）

**采用候选 A（相位折叠模板扣除）**；B 留作对照；C 弃。26px 与 13px 半阶口径在 W3.3 原型内实测取优（见 §5.3）。

## 8. 风险与未决

- 观测区若无真水印成分（例如含同场次背景材质），扣除仍以 ≤2 灰度级幅度作用于该区域，影响有限（W3.3 样张目检把关）。
- 测试_1.png 无场内观测量：W3.3 需确定其分支（沿用共享口径 vs 跳过显著扣除），并在指标表中单列。
- 阈值与门槛数值在 W3.4 定稿（写入 `docs/验收清单.md` 阶段 3 并回写 `watermark-removal` 规格）；定稿前阶段 3 不签收。
