## 1. 抠图算法语义（原图 → 底图）

### 1.1 输入输出约定

- 支持扩展名 `jpg / jpeg / png / bmp / gif / tif / tiff`（大小写不敏感）；输出为「主名 + `.png`」；同名覆盖、不做备份。（`抠图工具.cs` L306-L315；`openspec/specs/badge-cutout/spec.md` L18、L19、L23）
- 输出目录不存在时自动创建；exe 首次运行自动创建「原图」「底图」；脚本版输入目录缺失时报错停止：`找不到原图文件夹: <路径>`（exit 1）。（`badge-cutout` spec L20-L22；`抠图工具.cs` L354-L359；`cut_badge.ps1` L321-L322）
- 单张失败不中断批量：失败行 `[失败] 文件名  原因`，末尾汇总成功 / 失败张数。（`抠图工具.cs` L331-L348；`badge-cutout` spec L151-L155）

### 1.2 扫描线布局（水平 20 + 垂直 20 = 共 40 条）

- **水平线 20 条**（`int hLines = 20`）：`y = h × (0.14 + 0.72 × li / (hLines−1))`，即均匀覆盖图像高度约 **14%–86%** 区间；每条线从左右两侧向图像中线扫描。（`抠图工具.cs` L127-L131、L136-L147、L152-L164）
- **垂直线 20 条**（`int vLines = 20`）：`x = w × (0.14 + 0.72 × li / (vLines−1))`，覆盖宽度约 **14%–86%**；从上下两侧向中线扫描。（`抠图工具.cs` L170-L174、L179-L190、L195-L207）
- 合计 **40 条扫描线**——这就是"40 条扫描线布局"的确切含义。（`总结文档.md` L34；`badge-cutout` spec L37）

### 1.3 起始端边缘带取背景参考色

- 每条扫描线**先**在起始端 **5%–10% 边缘带**内取平均色作为该线背景参考色：
  - 水平线（左端）：`x ∈ [5%w, 10%w)`；右端同理取 `[90%w, 95%w)`；（`抠图工具.cs` L133-L135、L149-L151）
  - 垂直线（顶端）：`y ∈ [5%h, 10%h)`；底端取 `[90%h, 95%h)`。（`抠图工具.cs` L176-L178、L192-L194）
- 语义：参考色是**逐线本地背景估计**（取自边缘背景带），对渐变背景、局部阴影不敏感。（`badge-cutout` spec L38）

### 1.4 边界判定规则

- 判定条件：以候选像素为中心、水平方向 **9 像素**（`x−4 … x+4`）邻域的均值色，与参考色的 `|ΔR| + |ΔG| + |ΔB|` **大于 ScanT** ⇒ 记为该方向的边界候选点（四个方向各自独立扫描）。（`抠图工具.cs` L140-L147、L157-L164、L183-L190、L200-L207；`badge-cutout` spec L39）
- 扫描路径（水平左→右）：从 `x = 14%w` 起步、每步做 9 像素邻域平均，第一个超阈值位置记为左边界；右边界从 `86%w` 向回扫。（`抠图工具.cs` L136-L147）
- 候选点总数 **< 6** 直接失败：`ERR 边界点不足(N)，未找到圆形徽章`。（`抠图工具.cs` L213）

### 1.5 ScanT（默认 45）的调参语义

- 语义：颜色跃变阈值，量纲为 RGB 三通道差值之和；**默认 45**；GUI 可调范围 **10–200**；脚本版 `-ScanT` 可调。（`抠图工具.cs` L421；`总结文档.md` L45；`badge-cutout` spec L100、L114）
- **调小（更敏感）**：边界对比不明显（浅色徽章）时使用；**调大（更钝）**：背景噪点多、浅纹理误触发时使用。（`使用说明.txt` L26；`总结文档.md` L45）
- 它只影响"圆边界能不能被扫到"（扫描可行性），**不参与圆内 / 圆外判定**——圆内像素一律保留（见 1.8），所以调参不会把圆内浅色内容抠掉。（`badge-cutout` spec L46-L48、L69-L73）

### 1.6 RANSAC 圆拟合（600 次、容差 4px、固定种子）

- **固定随机种子**：`new Random(2024)` ⇒ 同一输入必须得到同一结果（可复现）。（`抠图工具.cs` L217；`badge-cutout` spec L59）
- **600 次迭代**；每次随机取 3 个候选点定圆（行列式法 `CircleFrom3`）；三点共线（行列式近 0）跳过该次采样。（`抠图工具.cs` L215-L222、L37-L46；`总结文档.md` L35；`badge-cutout` spec L54）
- **单次采样的合理性约束**（先过滤，避免离群模型）：半径 ∈ **[0.10, 0.70]×min(宽,高)**；圆心 ∈ 图像中央 **15%–85%** 矩形。（`抠图工具.cs` L226-L227；`badge-cutout` spec L55）
- **内点容差 4.0px**（`|点到圆心距离 − r| ≤ 4.0`）；取内点数最多者为最优圆。（`抠图工具.cs` L228-L233；`badge-cutout` spec L56）
- 最大内点数 **< 8** 判定失败：`ERR 未找到可靠的圆形(最多内点 N)`。（`抠图工具.cs` L236；`badge-cutout` spec L56）

### 1.7 Kasa 最小二乘精修（容差 5px）

- 第一步：取距 RANSAC 圆 **≤ 6.0px** 的点作为精修输入集（比 4px 容差略宽）。（`抠图工具.cs` L239-L243）
- 第二步：**Kasa 最小二乘迭代** `FitCircle(inPts, tol=5.0, iters=6)`：
  - 每轮闭式解出 (cx, cy)；r 取"所有内点到圆心的平均距离"；随后按 **5px 容差重选内点**；内点集合不变时提前收敛退出。（`抠图工具.cs` L49-L99、L246；`cut_badge.ps1` L36-L95；`badge-cutout` spec L57）
- 第三步：**接受 / 放弃**——精修结果必须同时满足：内点 ≥ 8、半径 ∈ **[0.08, 0.75]×min(宽,高)**、圆心在图内（`0 < cx < w`、`0 < cy < h`）；否则**保留 RANSAC 结果**（精修只能改善、不能劣化）。（`抠图工具.cs` L247-L252；`badge-cutout` spec L58）

### 1.8 羽化（默认 4）与"浅色内容不误抠"

- alpha 三区定义（d = 像素中心到圆心距离）：
  - `d ≤ R` ⇒ alpha = 255（圆内**全部保留**）；
  - `d ≥ R + Feather` ⇒ alpha = 0；
  - 两者之间**线性斜坡**：`alpha = (R + Feather − d) / Feather × 255`（四舍五入取整）。（`抠图工具.cs` L265-L271；`badge-cutout` spec L69-L71）
- **Feather 默认 4px**；GUI 可调范围 **0–20**；脚本版 `-Feather` 可调。（`抠图工具.cs` L425；`cut_badge.ps1` L5；`badge-cutout` spec L100）
- 用途：叠到任何底图上无锯齿；同时保证**圆内白色文字 / 浅色纹样完整保留、无透明空洞**——这就是"浅色内容不误抠"的机制：圆内 alpha 恒为 255、RGB 原样复制，扫描阈值管不到圆内内容。（`总结文档.md` L25-L26；`使用说明.txt` L37；`badge-cutout` spec L72）
- 实测对照：`测试_1.jpg` 不透明像素 177,418 ≈ π×238²（吻合率 99.7%），证明圆内无缺失、无空洞。（`总结文档.md` L81）

### 1.9 边距（默认 4）与外接正方形裁切

- 裁切范围 = **圆心 ±（半径 + Feather + Margin）**的外接正方形；裁切框超出原图边界时**夹取到图内**（不报错）。（`抠图工具.cs` L254-L258；`总结文档.md` L37；`badge-cutout` spec L85-L88）
- **Margin 默认 4px**；GUI **不暴露** Margin（固定 4），脚本版 `-Margin` 可调。（`抠图工具.cs` L421-L425、L503；`cut_badge.ps1` L6；`badge-cutout` spec L100-L101）
- 输出尺寸 ≈ `2 × (R + Feather + Margin) + 1`，因取整（int 截断 / 夹取）可能出现 **±1 像素**：实例 R=200 → `417×417`；R=199 → `416×415`。（`抠图工具.cs` L255-L261；`运行日志.txt` L6-L12；`docs/金标准数据.csv`）
- 输出 **32 位 ARGB PNG**（`Format32bppArgb`）；RGB 从原图**逐字节复制**，本阶段不做任何调色 / 去噪。（`抠图工具.cs` L273-L293；`badge-cutout` spec L73、L89）

## 2. 排版语义（底图 + 排版demo.png → 已排版）

### 2.1 模板与槽位识别

- 模板 `排版demo.png`：**2480×3508**（A4 300dpi 竖版白底），当前 **11 个**圆形槽位。（`排版日志.txt` L4-L5；`PROJECT.md` L111；`排版工具使用说明.txt` L6）
- 槽位识别方式（连通域）：
  1. **step=4 降采样**；前景判定 `|R−255| + |G−255| + |B−255| > 60`（模板为白底模型）；（`排版工具.cs` L100-L108；`badge-layout` spec L18）
  2. 4 邻域连通域求包围盒；**采样像素数 < 300** 的连通域丢弃；（`排版工具.cs` L143-L147；`badge-layout` spec L20）
  3. 两包围盒**交并比 > 0.3** 时合并（一个圆被切成多块的情况）；（`排版工具.cs` L138-L161；`badge-layout` spec L21）
  4. 按「先上后下、同高再从左到右」排序（实现为 bbox **顶边 y** 再 **左边 x**，见 2.2）；（`排版工具.cs` L163-L166；`badge-layout` spec L22）
  5. 每个包围盒**外扩 6 像素**后用"包围盒中心十字线扫描法"拟合圆：在中心行 / 列取前景弦，**圆心 = 弦中点，半径 = max(水平弦长, 垂直弦长) / 2**；半径 ≤ 10 视为失败丢弃；（`排版工具.cs` L170-L179；`layout.ps1` L65-L97；`badge-layout` spec L23-L24）
  6. **半径 < 300 丢弃**（图案内部小元素）；识别不到任何槽位报错。（`排版工具.cs` L177、L181-L184；`badge-layout` spec L25-L26）

### 2.2 填充顺序与自然排序

- 底图按**文件名自然排序**（Windows `StrCmpLogicalW`），保证 `1, 2, …, 10, 11` 不乱序。（`排版工具.cs` L15、L186；`排版工具使用说明.txt` L40；`badge-layout` spec L40）
- 每页槽位数 = 识别出的槽位数（当前 11）；第 `1..N` 张 → 第 1 页、第 `N+1..2N` 张 → 第 2 页，以此类推；页内按槽位排序依次填入；最后一页不足时**多余槽位留白**。（`排版工具.cs` L220-L223、L234-L245；`badge-layout` spec L38-L43）
- **排序实现细节（重放须复刻）**：排序键是 bbox **顶边 y**、再是**左边 x**（`merged.Sort` 比较 `a[1]` 再 `a[0]`，`排版工具.cs` L163-L166）——不是槽位中心的严格"从左到右"。后果示例：底行两槽按 y0 排序结果为**先右后左**（#10 右、#11 左），若新实现改用"中心坐标先左后右"，槽位分配表将与基线不一致。

## 3. 水印问题特征与旧三条路线（仅背景）

> ⚠ **本节只作问题域背景。重写去水印从零设计，不背旧实现；旧去水印输出不得作为验收标准**（`docs/验收清单.md` L72-L74）。

### 3.1 水印问题特征

- 形态：一层**约 13px 的小字符**，按**约 27px 的方格斜向铺满全图**；**亮度只比周围高几个色阶**，肉眼几乎看不清。（`remove_watermark.py` L5-L7；`PROJECT.md` L110）
- 旧实现的点阵建模常量（供理解问题域）：点模板尺寸 `TSZ = 21`、点形高斯标准差 `SIGMA = 4.4`、点阵间距 `PITCH = 27.0`、单点扣除幅度范围 `1.0–16.0` 灰度级、单像素累计扣除上限 `18.0`。（`remove_watermark.py` L27-L31）

### 3.2 旧三条路线：思路与局限

| 路线 | 实现 | 思路 | 局限（仅背景） |
| --- | --- | --- | --- |
| 细纹压制 | `detex.py` | 中值滤波 + 线性插值三档：`轻=0.35 / 中=0.65 / 重=1.0`，`结果 = 原图 + k×(中值−原图)`；只改亮度（三通道等量）、alpha 原样透传 | 全局平滑：重档降纹 ~85% 但"画面明显变干净 / 变软"；不对水印形态建模，属手段近似 |
| 点阵精确扣除 | `remove_watermark.py` | 残差域（灰度 − 中值21）高斯点模板 NCC 匹配（阈值 0.45）→ 实测点形 → 相位搜索（pitch=27；峰值 ≥1.5 且比其他相位 90 分位高 ≥0.6）→ 平滑区按实测笔画扣除 / 纹理区按格点扣除；未锁定时降级"逐点模式" | 依赖"水印 = 可建模的重复点阵"与相位显著性；只做**减法**扣除（假设加性亮纹）；pitch 等参数需与实际水印对齐 |
| AI 重绘 | `remove_watermark_ai.py` | 本地 ComfyUI（SD 1.5 img2img）整图重绘：白底合成 → 最长边 512 → 重绘 → 裁回原尺寸；seed 由输入文件 CRC32 固定 | 依赖本地服务（`127.0.0.1:8188`）；512 缩放损失细节；属整图重绘、改动整体画面（非"只改像素"）；跨环境不可 bit 级复现 |
