徽章排版工具(排版工具.exe)使用说明
====================================

【工具作用】
把「底图」文件夹里抠好的圆形徽章图片,按照「排版demo.png」版面自动排版:
- 自动识别模板上的圆形徽章槽位(当前模板共 11 个)
- 每 11 张徽章排成一页,输出 PNG 图片到「已排版」文件夹
- 最后一页不足 11 张时,多余的槽位留白
- 输出图片尺寸与模板一致(2480×3508,白底)

【文件结构】(所有文件放在工具同目录下)
├─ 排版工具.exe        ← 双击运行
├─ 排版demo.png        ← 排版模板,修改它即可换版面
├─ 底图\               ← 抠好的徽章 PNG(透明背景),如 1.png、2.png …
├─ 已排版\             ← 输出目录(自动创建,每次运行自动清空旧结果)
│    └─ 第1页.png、第2页.png …
└─ 排版日志.txt        ← 每次运行自动生成,可查看处理记录

【系统要求】
- Windows 10 / Windows 11:无需安装任何东西,拷过去双击就能用。
- Windows 8 / 8.1:也能直接用(系统已自带所需组件)。
- Windows 7:需先安装 .NET Framework 4.x(微软官网免费下载)。
- 不依赖 Python、PowerShell、Office 或任何第三方软件。

【换新电脑使用】
把整个文件夹拷贝到新电脑即可,建议至少包含:
排版工具.exe、排版demo.png、底图\、(如要在新电脑上抠图,
再带上 原图\、抠图.bat、cut_badge.ps1)。「已排版」文件夹会自动创建。
注意:从其他电脑拷贝的 exe 首次运行如果弹 SmartScreen 提示
("Windows 已保护你的电脑"),点「更多信息」→「仍要运行」即可。

【使用步骤】
1. 把要处理的图片放进「原图」文件夹,双击「抠图.bat」,
   徽章会自动抠到「底图」文件夹(已有底图可跳过这一步)。
2. 双击「排版工具.exe」,等待窗口显示"完成"。
3. 打开「已排版」文件夹查看结果。

【排版规则】
- 槽位位置、大小全部从「排版demo.png」自动识别,无需手动设置。
- 底图按文件名自然排序(1, 2, 3 … 10, 11 不会乱序),依次填入槽位:
  第 1–11 张 → 第1页,第 12–22 张 → 第2页,以此类推。
- 每页槽位按从上到下、从左到右的顺序填入。
- 每张徽章自动缩放到槽位大小并居中,透明背景自动保留。

【常见问题】
1. 提示"找不到模板文件"
   → 确认 排版demo.png 与 排版工具.exe 在同一个文件夹里。
2. 提示"底图文件夹里没有可用图片"
   → 确认「底图」文件夹里有 PNG 图片;如果是刚拍的原始照片,
     先放进「原图」文件夹跑一遍「抠图.bat」。
3. 想换排版版面
   → 直接替换 排版demo.png,槽位会自动重新识别。
     模板要求:白底图片,上面有圆形徽章图案位。
4. 想调整每页张数
   → 版面由 排版demo.png 决定,模板上有几个圆,一页就排几张。
     例如换成只有 9 个圆的模板,就变成每 9 张一页。
5. 新电脑上提示"无法运行"
   → 极少数旧系统缺少 .NET Framework 4.x,到微软官网下载安装即可;
     Windows 10/11 不会出现这个问题。
