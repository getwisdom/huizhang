# 徽章抠图工具 — 总结文档

> 日期：2026-10-04
> 目标：把「原图」文件夹中每张图片中间的圆形徽章自动抠出，输出透明 PNG 到「底图」文件夹。

---

## 1. 交付物清单

| 文件 | 说明 |
| --- | --- |
| `徽章抠图.exe` | 图形界面主程序，双击即用，无需安装任何依赖 |
| `抠图工具.cs` | exe 的 C# 源码（可用系统自带 csc.exe 重新编译） |
| `cut_badge.ps1` | 命令行脚本版，可调参数、可看中间过程 |
| `抠图.bat` | 脚本版的双击入口 |
| `使用说明.txt` | 简要使用说明 |
| `总结文档.md` | 本文档 |

---

## 2. 功能特性

- **自动定位圆形**：无需指定位置和大小，自动扫描边界点并拟合圆形。
- **抗干扰**：RANSAC 稳健拟合自动剔除边框条、云纹、飘带等干扰点。
- **圆内完整保留**：圆形区域内所有内容（包括白色文字、浅色纹样）全部保留、不透明，无空洞。
- **边缘羽化**：圆形边缘默认 4px 平滑渐变，合成到任何底图上都自然无锯齿。
- **批量处理**：一次处理文件夹内全部图片（jpg/jpeg/png/bmp/gif/tif）。
- **输出透明 PNG**：同名 .png，32 位 ARGB 带透明通道。

---

## 3. 工作原理

1. **逐线扫描**：从图片四边向中间，在水平 + 垂直共 40 条扫描线上，找第一个颜色跃变超过阈值的点，作为徽章外轮廓候选点。
2. **RANSAC 圆拟合**：随机取三点定圆共 600 次，取内点数最多的圆（容差 4 像素），再用 Kasa 最小二乘法精修圆心与半径。
3. **掩码生成**：圆内 alpha = 255（全部保留），圆外 alpha = 0，边缘按羽化宽度线性过渡。
4. **裁切输出**：按圆的外接正方形加边距裁切，保存为透明 PNG。

---

## 4. 参数说明

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 扫描阈值 ScanT | 45 | 边界扫描的颜色跃变阈值（RGB 三通道差值之和）。边界对比不明显时调小，背景噪点多时调大 |
| 羽化宽度 Feather | 4 | 圆形边缘羽化宽度（像素），越大边缘越柔和 |
| 边距 Margin | 4 | 输出图片四周留白（像素） |

- 图形界面：扫描阈值和羽化宽度可直接在界面上修改。
- 命令行批处理：`徽章抠图.exe --batch`（日志写入 `运行日志.txt`）。
- 脚本版：`powershell -ExecutionPolicy Bypass -File cut_badge.ps1 -ScanT 45 -Feather 4 -Debug`

---

## 5. 使用方法

**exe 图形界面**
1. 双击 `徽章抠图.exe`；
2. 把要处理的图片放进程序所在目录下的「原图」文件夹（首次运行会自动创建）；
3. 点击「开始抠图」；
4. 完成后可选择直接打开「底图」文件夹查看结果。

**脚本版**
1. 图片放入「原图」文件夹，双击 `抠图.bat`；
2. 或命令行运行 `cut_badge.ps1`（可加参数）。

## 7. 已知限制

- 工具按「徽章是完整圆形」设计；非圆形徽章不适用。
- 圆形之外的装饰（飘带、边框、角落图案）会被裁掉。
- 输出文件会覆盖同名旧文件。
- 运行环境要求 Windows 自带 .NET Framework 4.x（Windows 10/11 已内置，无需额外安装）。
