# 提案：layout-center —— 排版圆心实测校正（徽章与定位点改用模板圆盘实测圆心）

## Why

- 使用者现场（打包版 `dist\koutu\`，模板 2462×3503 + 12 张真底图）复跑后反馈：**「最好能完全对齐，似乎还是有偏差」**。
- 逐像素实测定位到根因：**上一次只修了「半径」，没有修「圆心」**。
  - 半径侧（layout-fit）已修好：检测半径被花色干扰为 412–428px，实测圆盘恒为直径 824px（r≈411.7），徽章外缘已贴在圆盘边界上。
  - 圆心侧仍是检测值：对使用者现场输出 `第1页.png` 与模板 `排版demo.png` 分别做圆拟合（自圆盘外向内取首个非白边界点 + 截尾圆拟合，内点率 94–98%），**模板圆盘实测圆心 y 比检测圆心低 0.1–15.9px（11 槽位中 6 个 +10.6~+15.9px、2 个 +1.3/+0.9px、3 个 ≈0）**，而徽章画的正是检测圆心 → 徽章整体比圆盘高 12–16px：**上缘压过圆盘上边界、下缘露出 12–16px 宽的圆盘图案月牙**（使用者看到的「偏差」）；定位点同源，也跟着偏。
  - 实测可靠性的旁证：11 个实测圆心落在行距 **442.6px 等距网格**上（411.66/411.68/… 与 2049.6/1230.6… 同列一致），而检测圆心不满足该网格。
- 检测圆心为何偏移：`detect_slots` 的包围盒来自前景连通域，图案模板上花纹会粘连进包围盒，`_fit_circle_cross` 的「包围盒中心十字弦」随之被抬高（半径同时被放大，见 layout-fit）。**检测算法冻结不改**，本次只在「绘制中心」层增加实测校正。

## What Changes

- **新增 `_measure_slot_center`（badge-layout）**：以检测槽位为种子，自圆盘外向内取「首个连续 3 像素非白」为边界点（圆盘之外是白底 `#FFFFFF`），以边界点质心为初值做截尾圆拟合（Kåsa，3 轮，内点容差 3px，720 个角度）得实测圆心；候选点不足、拟合半径异常（<300px 或与检测差 >80px）或圆心修正 >40px 时**回退检测圆心，不报错**。
- **绘制中心统一为实测圆心**：徽章合成（`_render_slot_patch(..., center=)`）与定位点（`_draw_anchor`）共用；半径仍取既有 `_fit_slot_radius`（语义不变，旧模板 414.0 / 现场模板 412.0）。
- **日志证据**：`排版日志.txt` 增加一行「圆盘实测」（槽位数、半径范围、圆心最大修正）；槽位分配表打印**实际使用**的圆心坐标（`p1 slot# 1 (412,435) <- 八两.png` 同义）。
- **兼容**：入库旧模板（2480×3508）实测圆心与检测差 (+0.12,+0.07)px ⇒ 输出近似逐像素不变，旧 golden 对照与定位点用例照旧通过；现场模板 11 槽位圆心修正 +0.1~+15.9px，徽章外缘与圆盘边界贴合（圆心残差 ≤1px）。
- **测试**：新增 `tests/test_layout_center.py`（几何：实测圆心落在圆盘上；回退路径；徽章/定位点同源；日志行）；既有 `test_layout_anchors.py` / `test_layout_golden.py` / `test_cli_layout.py` 回归。

### 非目标（Non-Goals）

- 不改 `detect_slots`（连通域 + 包围盒中心十字弦）与其输出——它继续负责「有哪些槽位」，本次只在「绘制中心」层校正。
- 不改半径语义与定位点几何参数（顶端距外缘 8.5px / 高 17px / 底宽 24px）；不新增 GUI / CLI 选项；不动目录契约、输出命名与清空语义。
- 不处理仓库根新增的未跟踪文件 `无图模板.jpg`（2462×3503 CMYK，当前检测 0 槽位）——超出本次范围，另行提案。

## Capabilities

### Added Capabilities

- `badge-layout`：新增需求「圆盘圆心实测（绘制中心校正）」。

既有需求（「模板槽位识别」「页面合成与缩放」「定位点绘制」）的**行为语义不变**，只把「绘制中心」的来源由检测圆心换成实测圆心；因 `flexible-io` 变更同时重写了「页面合成与缩放」块，本次不复写该需求，改用新增需求承载，避免他线提案再次过期。
