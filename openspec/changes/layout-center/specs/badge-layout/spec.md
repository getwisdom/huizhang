# Spec Delta —— badge-layout（圆盘圆心实测校正）

## Purpose

把「绘制中心」的来源从**检测圆心**改成**模板圆盘实测圆心**：检测算法冻结不变，但它在图案模板上会被花纹抬高圆心，
导致徽章与定位点整体偏移（使用者现场实测 0.1–15.9px，多数 +11~+16px）。本次以一次独立的圆盘边界圆拟合校正绘制中心。

## ADDED Requirements

### Requirement: 圆盘圆心实测（绘制中心校正）
系统 SHALL 在排版绘制前，为每个检测到的槽位实测模板圆盘圆心，并以实测圆心作为**徽章合成与定位点绘制的共同中心**。实测方法 SHALL 为：以检测槽位为种子，自圆盘外向内（外起点 = 检测半径 +60px、内终点 = 检测半径 −170px，均按图像边界裁剪、扫描上限 470px）按 720 个角度采样，取每个方向上「首个连续 3 像素非白（`min(R,G,B) < 246`）」的位置为边界点（圆盘之外视为白底），先以边界点质心为初值、再以代数圆拟合（Kåsa）做最多 3 轮截尾迭代（内点容差 3px）得到圆心与半径；当有效边界点少于 180 个、拟合半径小于检测半径的 50%、拟合半径与检测半径相差 > 80px、或实测圆心相对检测圆心位移 > 40px 时，SHALL 回退为检测圆心且不报错；位移小于 1px（亚像素噪声）时 SHALL 沿用检测圆心，保证既有模板输出逐像素不变。圆径缩放继续沿用「页面合成与缩放」的实测圆径（本次不改半径语义）。排版日志 SHALL 保留既有统计行语义，并追加一行「圆盘实测」，其中包含槽位数量、实测圆径范围与圆心最大修正量。

#### Scenario: 图案模板上校正圆心（使用者现场模板）
- **WHEN** 用带花色图案的模板（2462×3503）排版：检测圆心被图案抬高（实测 11 个槽位修正 +0.1~+15.9px，实测圆径 r≈411.7）
- **THEN** 徽章与定位点按实测圆心绘制，徽章外缘与模板圆盘边界贴合（圆心残差 ≤1px，不再出现一侧压边、一侧月牙）

#### Scenario: 干净模板保持不变（入库旧模板）
- **WHEN** 用入库旧模板（2480×3508，检测圆心与实测圆心相差 ≤0.2px）排版
- **THEN** 输出与校正前一致（页数、分配表、像素阈值照旧，坐标差 ≤2px）

#### Scenario: 实测失败安全回退
- **WHEN** 模板圆盘之外不是白底、或边界点不足/拟合异常（如纯色整页、圆盘内才有的小图案）
- **THEN** 该槽位回退为检测圆心继续排版，不报错，日志照常输出

#### Scenario: 徽章与定位点同源
- **WHEN** 开启定位点运行时
- **THEN** 定位点与徽章使用同一实测圆心与实测圆径（定位点顶端相对圆盘外缘的位置与既有几何一致）

#### Scenario: 日志可核对
- **WHEN** 任意一次排版运行
- **THEN** `排版日志.txt` 出现「圆盘实测」行（槽位数 / 圆径范围 / 圆心最大修正），槽位分配表坐标为实际使用的圆心
