# 设计：anchor-red-dot —— 红点定位点的几何与颜色取值

## 现场模板红点实测（取值依据）

用现场模板 `排版demo.png`（2462×3503）逐槽位测「槽位圆心正上方」窗口内的纯红像素（判据 `R>140 且 R-G>60 且 R-B>60`）：

| 槽位 | 红点 bbox | 圆心相对槽位圆心 | 中心半径 | 颜色中位 |
| --- | --- | --- | --- | --- |
| #01 | 34×27（被页面顶边裁切） | dx +5.7 / dy −420.9 | 421.0 | (254, 0, 0) |
| #04 | 35×34 | dx +5.7 / dy −426.3 | 426.3 | (254, 0, 0) |
| #05 | 31×30 | dx −0.1 / dy −422.4 | 422.4 | (254, 0, 0) |
| #08 | 32×33 | dx +0.1 / dy −424.2 | 424.2 | (254, 0, 0) |
| #09 | 34×28 | dx −0.2 / dy −420.5 | 420.5 | (254, 0, 0) |
| #10 | 34×26 | dx −0.4 / dy −421.0 | 421.0 | (254, 0, 0) |
| #11 | 33×26 | dx −0.1 / dy −420.2 | 420.2 | (254, 0, 0) |

- 7 个槽位是紧凑圆点：直径 31~35px（中位 ≈33px）、横向居中于槽位圆心（|dx| ≤ 6px，多数 ≤0.5px）、**中心半径 ≈ 420~426px**；该模板实测圆盘半径 411.7px ⇒ 中心距圆盘外缘 ≈ **+9.6px**（红点跨在圆外缘上：约 1/3 压住圆盘内侧、2/3 在外）。
- 颜色恒为 `(254, 0, 0)`（CMYK 满红经转换后的纯红）。
- 另外 4 个槽位（#02/#03/#06/#07）的红像素与相邻花纹粘连（bbox 90~139px 宽），取不到干净圆点；入库旧模板无红点（仅 1 处 49px 花纹边）。

## 自绘参数（写进内核常量）

| 常量 | 取值 | 说明 |
| --- | --- | --- |
| `ANCHOR_DOT_DIAMETER` | 32.0 | 实测中位 33px，取 32（含 1px 抗锯齿过渡后视觉约 33px） |
| `ANCHOR_DOT_GAP` | 9.5 | 红点圆心距**圆盘外缘**（向外为正）；由实测「中心半径 − 圆盘半径 ≈ +9.6px」取 9.5 |
| `ANCHOR_DOT_COLOR` | `(254, 0, 0)` | 与模板红点同色 |

绘制：`_draw_dot` 用「点到圆心的距离场 + 1px 抗锯齿」覆盖式绘制（与 `_draw_anchor` 同一套写法：`cover = clip(r_dot + 0.5 − dist, 0, 1)`，纯色按 cover 混合进画布），只改 RGB。

## 为什么是「自绘统一红点」而不是「搬运模板红点」

- `layout-fit` 已定向：定位点一律本工具自绘、统一、不取模板内容（搬运模板像素曾把红点/花纹碎片贴进输出）。
- 现场模板的红点本身就统一（居中、中心半径一致），自绘统一红点与模板落点重合（同一实测圆心 + 实测圆径 + 同一相对几何），既能满足付印对齐，又不受模板细节影响。
- 模板没有红点也能用（红点样式与模板无关，只是样式），符合既有「换模板不降级」的共识。

## 兼容与风险

- **默认不变**：`anchor_style="triangle"` 为默认，既有输出、golden 对照与像素数字完全不变。
- 日志行文案变化（加「样式：…」）会影响断言该行的用例与文档，需同步更新（已列入 tasks）。
- 红点与三角都只改 RGB、不参与徽章缩放；开关关闭时不绘制任何标记（与既有语义一致）。
- 红点有一部分落在圆盘内侧（跨圆外缘），会覆盖徽章最上缘 ~1/3 圆点高度的像素——与模板红点自身的落点一致（使用者模板即如此设计）。

## 验证

1. 红点样式实跑（现场模板 + 12 张真底图）：开/关差异仅限 11 个圆点区域；量得红点直径 32±1px、横向居中 ≤1px、中心半径 = 圆径 + 9.5±1px、颜色 `(254,0,0)`。
2. 默认（黑三角）复跑：`test_layout_golden.py` 的 `rgb>8=1141（0.0131%）`、开/关差异与 15/16 号汇报数字一致。
3. GUI：下拉默认「黑三角」、随勾选框禁用、记忆生效（`tests/test_gui_smoke.py`）。
