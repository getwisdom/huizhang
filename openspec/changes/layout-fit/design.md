# Design —— layout-fit（排版对齐 + 自绘定位点）

## Context

- 触发器：使用者换用新模板（2462×3503；11 个圆形徽章位；顶部有红色小圆点装饰；圆内为花色图案）实跑发现「出圈」，并定向：定位点改本工具自绘统一方案、红点不考虑、重点是徽章与模板圆形区域完全对齐。
- 实测（只读探针，仓库外 `D:\workspace\_koutu_anchor_probe\`）：
  - 旧模板：检测 r=414.0（11/11）；「过中心行最大宽度」重测 = 828/2 = **414.0**（11/11）——与检测一致。
  - 新模板：检测 r=412–428 不等（被花色干扰）；重测 = 824/2 = **412.0（11/11 完全一致）**；圆心 x 方向与检测一致（dx=0.0，11/11）。
  - 使用者输出对照：徽章外缘越出圆盘最多 ~17px（#04），最少 ~0.5px（#08/#11）——肉眼「出圈」。

## Goals / Non-Goals

**Goals**：徽章外缘与模板圆盘贴合（残差 ≤4px，含徽章柔边；此前最多 ~18px）；定位点自绘统一、与模板无关；旧基线行为零变化（逐像素）。
**Non-Goals**：不改 `detect_slots` 冻结算法；不做按模板标记自动适配；不新增 GUI/CLI 选项。

## Decisions

### D1 圆径重测（对齐）

- 方法 `_fit_slot_radius`：以检测槽位为种子，在中心行带 `cy±70`、单侧窗口 `±470` 内逐行扫描，内容判据 `min(R,G,B) < 215`，取最大宽度行；半径 = 宽度/2；失败、`< 300` 或 `|r_fit − r_det| > 80` 时回退检测值（护栏，不报错）。
- 备选（否决）：改 `detect_slots`——冻结基线算法与旧模板逐像素复刻不容扰动；问题在「绘制目标尺寸」而非「槽位识别」。
- 旧模板不动证明：重测 11/11 = 414.0 = 检测值 → 绘制目标完全一致（逐像素无变化，golden 复跑背书）。
- 新模板效果：目标 = 2×412+2 → 徽章外缘 ≈ 412.5 ≈ 圆盘外缘（+0.5px 工艺余量）；实测残差 +0.5~+3.5px（其中 ~1px 为既定 +1 画布余量、其余为徽章自身柔边；硬阈值下多数仅 +1~3px）——出圈消除（此前最多 ~18px）。

### D2 自绘定位点（统一方案）

- 参数（相对实测圆径 r）：顶端距圆外缘 8.5px；轴向高 17px；底半宽 12px（底宽 24px）；描边 6.5px（含约 1px 抗锯齿过渡）；近黑 `#0B090A (11,9,10)`（沿用原设计色）。
- 实现 `_draw_anchor`：点到三边线段的距离场 → 覆盖率（半描边内为 1、向外 1px 软过渡）→ 与画布混色（alpha 保持 255；中心空心透徽章）。
- 每槽位（含空槽）绘制同一标记；与模板内容无关；取消「含底/去底」与「未检测到标记降级」。
- 备选（否决）：继续补丁搬运（模板相关、搬运红点/花纹碎片——实跑 8/11 命中碎片）；内嵌旧三角位图（仍是搬运、不能按圆径统一）。

### D3 开关 / 日志 / 界面不变

- `anchors` 默认 True；GUI 勾选框与 `layout/anchors` 记忆不变；CLI `--anchors/--no-anchors` 不变。
- 日志：`定位点: 已开启（共绘制 N 处：每页 M 处 × T 页）` / `定位点: 已关闭`；无降级句；既有统计行语义不变。

## Risks / Trade-offs

- 重测依赖模板花色边缘：边缘过淡的模板可能低估 → 回退护栏 + 偏差上限（80px）；当前两套模板（旧 414.0 / 新 412.0）验证通过。
- 标记为本工具统一方案，样式参数集中于常量；使用者若另有定版图样，改参数即可（见 Open Questions）。
- 新模板左侧槽位圆盘贴页边（外缘约 x=−0.5）→ 测量按页内可见部分计算，误差 ≤0.5px。

## Migration Plan

- 无需数据迁移；包重建后使用者现场复跑即可（其模板与底图先备份、随新包恢复）。

## Open Questions
