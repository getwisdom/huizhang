# 提案：layout-fit —— 排版对齐（按模板圆径实测缩放）+ 自绘统一定位点

## Why

- 使用者换用新模板（2462×3503、11 个圆形徽章位，圆盘实物直径 824px）实跑：**徽章与模板圆形区域不对齐、"有点出圈"**——槽位检测半径被模板花色干扰（检测 r=412–428 不等，实物圆盘恒为 r=412），徽章外缘最多越出圆盘 ~17px；同时旧版「定位点」是"从模板搬运小区域"，在新模板上搬运到红点/花纹碎片（8/11 命中），观感错误。
- 使用者定向：**定位点改本工具自绘的统一方案（不取模板内容），红点不参与；重点是徽章与模板圆形区域完全对齐**。

## What Changes

- **排版对齐（badge-layout）**：槽位目标尺寸改为「以模板圆盘实物为准」——以检测槽位为种子，用「过中心行最大宽度」重测圆径后再缩放徽章；重测失败或偏差异常时回退检测值。旧基线模板重测 = 检测值（r=414.0，逐像素无变化）；新模板修正到 r=412.0（11 槽位一致），出圈消除（外缘贴合圆盘边界，残差 ≤4px；此前最多 ~18px）。
- **自绘统一定位点（badge-layout）**：定位点改为**本工具自绘**的黑色空心小三角（尖朝上、紧贴圆内缘；几何按实测圆径固定：顶端距外缘 8.5px、高 17px、底宽 24px、近黑描边），与模板内容无关；每个槽位（含空槽）绘制同一标记；取消「含底/去底」叠法与「未检测到标记降级」概念。
- **保持**：开关（默认开、可关）、GUI 勾选框与记忆、CLI `--anchors/--no-anchors`、日志行语义（开关状态 + 数量）、目录契约与输出命名，全部不变。
- **破坏性评估（行为）**：开启态定位点画法变化（补丁搬运 → 自绘标记）；旧基线数据**徽章渲染保持逐像素一致**（重测为空操作）；关闭态输出与关闭前基线一致（阈值照旧）。
- 对照/测试：pytest 新增/更新（统一性逐像素、开/关差异仅限标记区域、几何、CLI/GUI）；旧 golden 回归复跑；使用者现场（新模板 + 12 张真底图）复跑对照。

### 非目标（Non-Goals）

- 不改 `detect_slots` 冻结算法（连通域/十字弦）及其输出；对齐修正只发生在「绘制目标尺寸」层。
- 不做「按模板标记样式自动匹配」（红点/三角切换）——定位点只按本工具统一方案绘制。
- 不新增 GUI / CLI 选项；不改目录契约、输出命名与清空语义。

## Capabilities

### Modified Capabilities

- `badge-layout`：「页面合成与缩放」（按模板圆径实测缩放对齐）与「定位点绘制（默认开启、可关闭）」（自绘统一标记，取消降级态）。
