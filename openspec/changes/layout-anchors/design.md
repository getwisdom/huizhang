# Design —— layout-anchors（排版定位点）

## Context

需求与范围见 `proposal.md`；行为契约见本变更三份 spec delta（badge-layout / desktop-gui / pipeline-orchestration）。

现状（`koutu/core/layout.py`，只读勘察）：

- 模板 `排版demo.png` 只参与槽位识别（连通域 + 十字弦拟合；当前 11 个槽位、r=414），不绘入输出页；
- 页面合成 = 2480×3508 白底画布 + 逐槽位「底图补丁」（双三次、源叠加）；空槽留白；
- 因此模板上「圆内正上方的小三角」不会自动出现在输出页——本变更为主动搬运。

## Goals / Non-Goals

**Goals（设计层）**

- 把「照模板」落到可复现的几何与像素判据：补丁窗口、含底叠法、逐像素对照断言；
- 开关关闭零退化（旧基线逐项照旧）；换模板无标记安全降级；GUI / CLI / 内核同一语义与默认值。

**Non-Goals（设计层）**

- 不做模板元素的通用识别或元素库，不引入配置化的窗口参数（当前模板测量值直接固化成常量）；
- 不做三角的矢量重绘（实物像素含 AA 与不规则细节，「照模板」只能搬运）；
- 不把叠法（含底 / 去底）做成 GUI / CLI 选项（未在需求内；样张定稿后固化为默认）。

## Decisions

### D1 补丁搬运与补丁窗口

**方案**：补丁搬运——从模板提取「三角所在小区域」（与槽位相对定位），叠加到输出页同一相对位置。

- 窗口（相对槽位中心，运行时按槽位计算；**源 = 目标同一坐标**——模板与输出页同尺寸、同一槽位坐标系）：

  ```
  cx0 = floor(cx + 0.5)；cy0 = floor(cy + 0.5)
  x ∈ [cx0-20, cx0+20)（宽 40）；y ∈ [cy0-406, cy0-387)（高 19）  → 40×19 px
  ```

- 11 槽位逐一核验（探针 v5，关键数字）：
  - 三角整体位于窗口内：顶端 11/11 在窗口顶行（rel y=−405.5）；底端 rel y ∈ [−389.5, −387.5]；横向 rel x ∈ [−10.5, +12.5]；
  - 窗口顶行两侧最小值 11/11 为 240（无环混入）；窗口内除三角外为平场底色；
  - 窗口内暗像素（min<96）计数 185–215（用于降级阈值，见 D4）；
  - 已知例外：槽位10 窗口底行含一行浅灰（≥134，图案渐入）；个别槽位三角「腿」在窗口下缘外延续 1–2px（与各自圆内图案相连，被固定下缘裁掉——取舍见 Risks）。
- 窗口原点（模板绝对坐标，供复验）：(455,43) (1998,43) (1228,459) (455,911) (1994,911) (1225,1348) (451,1784) (2002,1789) (1227,2223) (1999,2660) (455,2662)。
- 备选（否决）：整圆搬运（会把圆环搬进输出页，需求只要定位点）；阈值重构三角（无法复刻实物像素细节）。

### D2 叠法与对照样张（定稿默认 = 含底）

- **含底（默认）**：补丁 RGB 原样覆盖（alpha=255）——输出页窗口区域与模板同区域**逐像素一致**（可做裁剪区域对照断言）；页面观感 = 三角自带其周围浅色底（空槽 = 白底上的 40×19 浅灰小矩形，属预期）。
- **去底（对照版）**：仅叠「暗笔画」——以暗度为不透明度（`alpha = 255 − min(R,G,B)`，≥235 视为全透明），底色不搬运、三角描边直接叠在徽章上。
- 内核保留叠法常量（默认含底），样张经叠法参数生成；**叠法不作为 GUI / CLI 选项**。两版（连同关闭版）样张交使用者目检（停2）；如需改默认为去底：翻转常量 + 同步规格文字。
- **停2 定稿（2026-10-06）：使用者目检后按「含底」收敛（保持默认）**；样张与数字见 `docs/汇报/15-排版定位点.md`。
- 原因：两版观感取舍（白底小矩形 vs 描边叠色）只有使用者能拍板；先按指示默认含底。

### D3 开关语义与默认值

- 内核 `run_layout_batch(..., anchors: bool = True)`；关闭 = 完全跳过定位点逻辑（不提取、不绘制，不新增像素操作）。
- GUI 勾选框与 CLI `--anchors / --no-anchors` 都映射到该参数；默认 True（默认开）。
- CLI 用 `argparse.BooleanOptionalAction`（Python 3.12 可用），中文 help；GUI 文案「添加定位点」。

### D4 降级（换过模板而无此标记）

- 判定：窗口内「暗像素（min<96）计数 ≥ 60」视作存在标记；否则跳过绘制、不报错，日志一句：`定位点: 已开启（模板上未检测到标记，已跳过）`。
- 依据：当前模板 11 槽位实测 185–215（最小 185）→ 阈值 60 留 ≥3 倍余量；仅当区域几乎无暗内容时落入降级。
- 边界：窗口超出图像边界（小半径模板）按可见区域判定 / 裁剪，不得抛异常。

### D5 日志行（一行；既有统计行不变）

- 既有行（`模板: …` / `识别到 … 个槽位` / `底图数量: …` / `共 … 页…` / 分配表 / `已生成 …` / `完成。…`）文案与语义不变；
- 在页循环结束后、结尾空行之前追加一行（三态）：
  - 开启且绘制：`定位点: 已开启（共绘制 N 处：每页 M 处 × T 页）`（N = M × T，按实际生成页数；取消按实际值）；
  - 开启但降级：`定位点: 已开启（模板上未检测到标记，已跳过）`；
  - 关闭：`定位点: 已关闭`。
- 说明：关闭态同样保留状态行（便于核对）；使用者如要求「关闭时与基线日志逐字一致」，删该行即可（一句话变更）。

### D6 GUI、设置与任务透传

- `LayoutPage` 增加「添加定位点」勾选框（默认勾选），加入排版页参数面；运行期间随 `set_busy` 禁用、结束恢复。
- 设置键 `layout/anchors`（bool）：加载缺省 True；随现有机制（程序根 `koutu.ini`；不可写回退 `%APPDATA%\koutu\koutu.ini`）。
- `make_layout_task(..., anchors=...)` 透传到内核；CLI 与 GUI 共用同一内核参数。

### D7 验收口径

- **关闭退化**：`tests/test_layout_golden.py` 以 `anchors=False` 运行，判据照旧（尺寸 / 页数 / 分配表 / 像素阈值）；`docs/验收清单.md` 阶段 2 命令补 `--no-anchors`。
- **开启新判据**（pytest + 实跑）：
  1. 补丁窗口裁剪对照：输出页每个槽位窗口与模板同区域逐像素相等（含空槽）——11/11；
  2. 空槽：末页留白槽位存在定位点（同一断言覆盖）；
  3. 降级：无标记小模板运行不报错、无新增像素、日志含跳过说明；
  4. 日志：开启含数量行；关闭含「已关闭」；既有统计行不变。
- **CLI**：默认与 `--no-anchors` 各一用例（退出码 0、日志、输出差异）。
- **GUI**：默认勾选、记忆回环、运行中禁用三用例（offscreen）。
- **打包**：重建后中文+空格路径冒烟（开 / 关各一页 + 三页签 / 退出码契约不破）。

## Risks / Trade-offs

- **窗口下缘 1–2px 裁切**：个别槽位三角「腿」在窗口外延续 1–2px（已与各自圆内图案相连，无法干净分离）；按固定下缘裁齐，换取 11 槽位一致的干净窗口（不把各圆花纹搬进输出）；300dpi 下不可辨。
- **含底观感**：空槽出现 40×19 浅灰（240）小矩形；去底版可消除——由样张目检定稿。
- **槽位10 底行浅灰**：属模板图案渐入（≥134），量级轻微。
- **并行变更顺序**：本变更 delta 全为 ADDED 新增需求，与 `flexible-io`（MODIFIED）在任意归档顺序下不冲突。
- **打包版无控制台**：CLI 开关证据以日志 + 退出码为准（沿用既有口径）。

## Migration Plan

- 默认开启 = 输出页新增定位点（非目录 / 命名契约破坏）：需要旧观感时 CLI 加 `--no-anchors`、GUI 去勾选；回归 / 验收命令按新口径（验收清单已更新）。
- 回滚：`anchors=False` 即旧行为；无需数据迁移。

## Open Questions

- 空槽是否改「只画已放徽章的槽」：默认画全部（与模板观感一致）；使用者一句话可改。
- 叠法默认（含底 / 去底）：**已定稿（停2，2026-10-06）= 含底**（目检结论：按含底收敛、保持默认）。
- 关闭态日志保留「已关闭」行：默认保留；如需与基线逐字一致可删。
