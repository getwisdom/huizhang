# 提案：flexible-io —— 选择目录 / 自定义输出与安全规则（自由输入输出目录）

## Why

- **操作者硬需求**（原话）："起码得支持选择目录，自定义输出目录名等。"当前 v1 的 CLI 已支持 `--src/--dst`，但 **GUI 仍是只读路径展示**（`koutu\gui\pages.py:71`），任务与「打开输出目录」都固定指向程序根——"选目录"缺的就是 GUI 层与规格口径。
- **关键安全题**（两轮评审各复现一次）：一旦允许自定义输出目录，排版"写入前清空输出目录旧 `*.png`"会**无差别删除操作者自己的 PNG**（实测 `我的照片.png` 被删）。必须先定安全规则，再放开入口。
- **成品实走发现**（`docs\汇报\14-产品评审.md`）：任务运行中关窗 → 进程 `0xC0000409` 崩溃退出；排版日志只记目录名、异常/取消不落盘；打包版 CLI 表述与实测不符；11/12/13 号汇报遗留 5 项确认项与归档后措辞待收口。
- 上述已按 14 号评审拍板收束为：**默认行为零变化**（双击即用不退化），自定义为**显式可选**；安全规则取「仅默认目录保留清空、自定义只写不删」。

## What Changes

- **GUI 选择目录（desktop-gui）**：抠图/排版页输入、输出目录可选（浏览 / 手输 / 恢复默认）；QSettings 记忆最近选择；「打开输出目录」跟随实际选择；五类校验（不存在 / 无权限 / 盘符 / 输出=输入 / 超长）与中文报错；运行期锁定路径控件。路线：**GUI 界面**。
- **安全规则（badge-layout + pipeline-orchestration）**：排版清空语义收窄——**仅默认输出目录（程序根下 `已排版`）保留"清空旧 `*.png`"；自定义输出目录不自动清理**，只按同名覆盖写入，并在日志记录"同名覆盖数 / 本工具旧页数（提示不清理）"；GUI 与 CLI 共用同一判定规则函数。路线：**排版 + 流程契约**。
- **健壮性与日志（desktop-gui + pipeline-orchestration）**：运行中关窗给中文确认（不再崩溃退出）；日志记**完整路径**，成功/失败/取消一律落盘并带中文状态行；任务开始前在日志与状态行给出覆盖/清理/输入张数计数提示。路线：**流程契约 + GUI 界面**。
- **文档与裁定收口（tasks 承载）**：`使用说明.txt` / `README.md` 修正 CLI 调用姿势与输出可见性表述、新增「自定义目录」与"换批次提示"章节；交付包命名为「koutu v1.1」；`AGENTS.md` / `PROJECT.md` / `openspec\config.yaml` 的"正在按提案重写"归档措辞改完成时并指向归档路径；五项遗留确认按 14 号评审裁定沿用/修正。路线：**文档（不属能力规格）**。
- **需要挂 golden 对照 / pytest 的条目**：排版清理语义变化 → 阶段 2 复跑 + 新增「自定义目录只写不删」判据；新增规则函数单测、日志口径用例、关窗保护用例；打包版冒烟追加自定义目录、关窗保护、CLI 调用姿势三条。

### 破坏性评估

- **非破坏性**：默认目录（`原图 → 底图 → 已排版`）与双击即用的默认行为**零变化**；CLI 既有命令参数面不变。
- 唯一行为变化：**自定义输出目录不再自动清旧页**——这是本次要建立的安全规则本身（新增能力的语义）；迁移方式：需要清空时改用默认目录或自行清理；自定义目录内本工具旧页会在日志中获得提示（不自动删除）。

### 非目标（Non-Goals）

- 不做页名前缀等"输出文件命名定制"（规格维持 `第N页.png` 无零填充、无日期前缀）；
- 不做控制台孪生 exe（`koutu-cli.exe`），改为文档修正（调用姿势 + 输出可见性）；
- 不做去水印算法（入口占位维持）；不做跨平台；
- 不改 13 个中文数据目录契约、不改默认参数；
- 本变更只落规格 / 设计 / 任务与验收口径，**不写产品代码**（实现列为任务由开发工程师执行）。

## Capabilities

### Modified Capabilities

- `desktop-gui`：参数、路径与设置记忆（目录选择/记忆/校验/打开跟随/运行期锁定）；统计行与结果呈现（运行前计数提示）；全中文与健壮性（运行中关窗保护）。
- `pipeline-orchestration`：数据目录契约与保留名单（显式自定义目录的边界）；运行日志与统计行（完整路径、兜底落盘、取消状态行、汇总按实际值）。
- `badge-layout`：页面合成与缩放（清空语义收窄为"仅默认目录"+ 自定义目录只写不删）。
