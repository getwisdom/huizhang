# Design —— flexible-io（选择目录 / 自定义输出与安全规则）

## Context

- 现状 v1：GUI 路径只读（`koutu\gui\pages.py:71`）、任务与「打开输出目录」固定程序根（`koutu\gui\main_window.py:46/49/70-90`）；排版"写入前清空输出目录旧 `*.png`"（`koutu\core\layout.py:457-461`）；CLI 已有 `--src/--dst`。
- 依据：`docs\汇报\14-产品评审.md`——成品实走（S1–S11）与拍板口径（其 §九）；安全实验 D2-2（自定义输出目录中 `我的照片.png` 被删）。
- 约束：默认行为不退化（golden 阶段 1/2/4）；中文契约与程序根约定不变；本变更只写规格 / 设计 / 任务与文档。

## Decisions

### D1 目录选择与默认值（GUI）

- 页面路径行 = 可编辑输入框 + 「浏览…」 + 「恢复默认」；默认值为程序根约定目录（`原图` / `底图` / `已排版`）。
- 相对路径按程序根解析（与 CLI 的 `paths.resolve_dir` 一致）；绝对路径原样使用。
- QSettings 记忆 `cutout/src`、`cutout/dst`、`layout/src`、`layout/dst`；不可用时回退默认并给中文提示。

### D2 校验（任务启动前，中文报错）

- 五类：目录不存在且无法创建 / 无写入权限 / 盘符或路径无效 / 输出目录与输入目录相同 / 路径过长（>259 字符）。
- 校验失败不启动任务；不得直出 `WinError` / 英文异常原文（异常层统一包装中文）。
- 自定义输出目录**只创建最后一级**（父目录必须已存在）；不隐式创建多级（防手误生成目录链）。
- 实现提示：Windows 下 `os.access` 不可靠，建议实际试写探测。

### D3 安全规则：排版清空语义收窄（核心决策）

- **默认输出目录** = 程序根下 `已排版`（按解析后的绝对路径判定，不论是否经选择器选中）：保留 v1 行为"写入前清空旧 `*.png`"（默认零变化）。
- **自定义输出目录**：不自动清理任何文件；只按同名覆盖写入；日志记录"同名覆盖 N 个 / 检测到本工具旧页 N 张（不清理）"。
- **实现形状**：核心保留**显式清理参数**（如 `run_layout_batch(..., clean_old=True)`，默认值维持现状 → 现有单测与调用不动）；"是否清空"的判定统一放在调用方共享的规则函数里（GUI / CLI 各接线一行）：`clean_old = (resolved_dst == resolved_default_layout_dir)`。

### D4 运行前提示（不打断操作）

- 任务开始前在状态行与日志给出计数：将覆盖的同名产物数、将清理（默认）或提示不清理（自定义）的旧页数、本次输入张数（排版为有效底图张数；配合使用说明"换批次先清空/替换『底图』"）。

### D5 健壮性：运行中关窗保护

- `closeEvent`：任务运行中弹中文确认「任务正在运行：继续等待 / 取消任务并退出」；选退出 → 先请求取消、在单张/单页边界收束后关闭。
- 目标：进程不再以崩溃码退出（v1 实测 `0xC0000409`）；无任务时关闭行为不变（干净退出 0）。

### D6 日志口径（两能力统一）

- 「模板 / 输入 / 输出」记**完整路径**（不得只写目录名）。
- 成功、失败、取消**都落盘**，含中文状态行（`错误: …` / `已取消：成功 X 张` / `已取消：已生成 X/Y 页`）；汇总统计按**实际发生值**记录，不得以计划值或「全部完成」掩盖取消/失败。
- 日志位置仍固定程序根（固定文件名不变——验收锚定）。

### D7 CLI 现状保持与文档修正

- CLI 命令参数面与默认行为不变；`--dst` 的清理判定与 GUI 同规则（指向默认路径才清空）。
- 自定义输出目录的"多级自动创建"（parents=True）本批保持现状（已过验收的路径不动），差异写入使用说明；如需两入口完全统一，另行拍板。
- 打包版 CLI：修正文档——输出会打印在当前控制台、cmd 下可直接等结果、PowerShell 用 `Start-Process -Wait`（或加管道）、完成判定以日志为准；不做 `koutu-cli.exe`（列入后续候选）。

### D8 遗留确认项裁定（14 号评审 §四，2026-10-06 拍板）

| 项 | 裁定 |
| --- | --- |
| 窗口标题 | 沿用「koutu · 徽章处理工具」 |
| 去水印占位文案 | 沿用「本功能后续版本提供」 |
| 「打开输出目录」 | 保持随时可点；跟随当前选择；缺目录按 D2 规则处理并中文提示 |
| 交付包命名 | 发布文件夹「koutu v1.1」；构建产物名 `koutu` 与打包脚本不动 |
| 控制台孪生 exe | 不做；文档修正；后续候选 |
| 归档后措辞 | 修正：`AGENTS.md`（第 4/8 行）、`PROJECT.md`（13/15/146 行）、`openspec\config.yaml`（context）改完成时并指向 `openspec/changes/archive/2026-10-06-python-pyqt-rewrite/` |

## 默认不退化论证（对照 golden 阶段 1/2/4）

- **阶段 1（抠图）**：未触碰抠图逻辑与默认路径；GUI 仅新增目录选择 → 判据与复跑口径不变。
- **阶段 2（排版）**：**默认目录"先清空后写"语义零变化**；新增"自定义目录只写不删 + 提示"；日志句调整为完整路径/兜底落盘（首行路径格式不在阶段 2 判据字段内）→ 重跑一次全量 + 执行新增判据。
- **阶段 4（打包）**：交付物结构与规模不变；追加三条冒烟：自定义目录跑通、运行中关窗保护、CLI 调用姿势复核。
- **通用红线**：13 个数据目录只读核对、像素级指标 + 日志统计行、禁逐字节 SHA——全部保持。

## Risks / Trade-offs

- **自定义目录旧页残留**：不自动清理 → 上次多页可能混入结果集；缓解 = D4 提示 + 使用说明"换批次先清空自定义目录"（已评估接受，换取"工具只写不删"的安全承诺）。
- **单级创建的用户教育**：父目录必须存在，错误时中文提示引导（比多级自动创建更安全）。
- **测试连带**：`tests\test_gui_smoke.py:37`（`isReadOnly` 断言）需按 D1 改写；新增规则函数 / 日志 / 关窗用例（实现期）。
- **两入口创建规则差异**：GUI 单级、CLI 多级（本批）；写入使用说明避免误判。

## Migration Plan

1. W1（本变更内）：规格 delta 定稿 + `docs\验收清单.md` 追加判据 + 文档修正（含归档措辞与 CLI 表述）。
2. W2（实现批，开发工程师）：GUI 目录选择/记忆/校验 → 关窗保护 → 规则函数与核心参数 → 日志口径 → 提示计数 → 测试更新与实跑。
3. W3（验收批）：新判据全量 + 阶段 0/1/2/4 复跑（源码 + 打包冒烟）→ `openspec archive flexible-io`。
4. 回滚：默认流程零变化；如需回退仅 revert 本变更相关提交（不改写历史）。

## Non-Goals（设计层）

- 输出文件命名定制、控制台孪生 exe、去水印算法、跨平台适配、目录契约与默认参数改动——均不做。
- 无遗留 Open Question（拍板已给出，见 D8 与 14 号评审 §九）。
